# gdrive-write-mcp

gdrive-write-mcp is a small program that lets an AI assistant edit files in a shared Google Drive. An assistant asked to change a document usually writes out a new copy and puts the old one in the bin. The text comes out right and everything else about the file is wrong. The link people had stops working, the people it was shared with lose access, and the earlier versions are gone. This one changes the document where it sits, so the file keeps its link, its sharing settings and its history, and Google records the edit as one more version. It can replace a whole document, swap one piece of text for another, or add a line at the top or the bottom. It refuses to write anything it cannot write safely: PDFs, pictures and other files that are not text, and every Google file type except Docs and Sheets, so it will not change a slide deck or a form. Before writing, it checks whether the file has changed since it read it, and refuses if it has.
